# **App Name**: Synthetic Faces Explorer

## Core Features:

- Project Visualization: Display project overview with clear sections for each stage: Data Preparation, WGAN Implementation, Hyperparameter Tuning, Classifier Training, and Results.
- Interactive Metrics: Interactive charts and graphs to visualize performance metrics like loss curves, accuracy, Inception Score, and FID scores.
- AI-Powered Summaries: Use a generative AI tool to create summaries of each part of the report, which can be expanded to reveal all details of that step of the study

## Style Guidelines:

- Primary color: Lilac (#C8A2C8) for a modern and calming feel.
- Secondary color: Light gray (#F0F0F0) for backgrounds and neutral elements.
- Accent: Deep purple (#800080) for interactive elements and highlights.
- Use clear and consistent headings and subheadings to improve readability.
- Use a consistent style for icons, ensuring they are related to the content and visually appealing.
- Single-page layout with anchor links for easy navigation.
- Subtle animations for transitions and loading states.
